# Security

## Reporting a vulnerability

Report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/aalvaropc/pusaq/security/advisories/new). Do not include credentials or private request data in public issues.

## Supported version

Security fixes target the current `main` branch. There is no guaranteed response time or production support commitment.

## Operating boundary

The Terraform runtime is a temporary measurement environment. It is not a production deployment template. Treat prompts, provider credentials, and request logs as sensitive data.
